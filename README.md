# Landing Page — Câncer: A Melhor Coisa que Me Aconteceu

## Deploy no Vercel

### Opção 1 — Arrastar e soltar (mais fácil)
1. Acesse vercel.com/new
2. Arraste esta pasta inteira para a tela
3. Clique em Deploy — URL gerada em segundos

### Opção 2 — Vercel CLI
```bash
npm i -g vercel
cd landing_vercel/
vercel --prod
```

## Antes de publicar
Substitua nos 3 lugares do index.html:
  https://link-prevenda.com.br
pela URL real da sua plataforma de pré-venda.
